#LeetCode, solved in a notebook.

A JupyterLab extension that turns any LeetCode question into a notebook. Write the solution, run the examples, and submit from the toolbar.

In [1]:
pip install jupyterlab-leetcode
Needs JupyterLab 4 and Python 3.12+ Watch the demo video

1. Two Sum

Given an array of integers nums and an integer target, return indices of the two numbers such that they add up to target.

EasyArrayHash Table
[1]:
from typing import List
[2]:
class Solution:
    def twoSum(self, nums: List[int], target: int) -> List[int]:
        seen = {}
        for i, n in enumerate(nums):
            if target - n in seen:
                return [seen[target - n], i]
            seen[n] = i

##No login screen. Use the browser you already have.

Open the LeetCode launcher in JupyterLab and pick the browser where you're already signed in to leetcode.com. The extension reads your LeetCode session cookie from that browser. It never sees or stores your password.

On macOS the system may ask for your keychain password the first time. This lets the extension read the browser's cookie store. You can choose "Always Allow".

##Every question becomes a notebook you keep.

Click a question and the extension writes a ready-to-run .ipynb next to your other work. Notebooks are grouped in folders of fifty. Your solutions stay on disk and can go in git.

  • descriptionThe question, its difficulty, topic tags, hints, and a link back to LeetCode.
  • solutionThe Python 3 starter code. Add more solution cells when you want another approach. Submit sends the last one.
  • examplesOne cell per example test case. LeetCode's null, true, and false are already converted to Python.

##Submit, and the verdict is written into the notebook.

The Submit button saves the notebook and sends your solution to LeetCode. When judging finishes, the result is written to a cell at the end of the notebook. The full result is also saved in the notebook's metadata.

  • ⏳Time Limit Exceeded with the last test case and how many passed
  • 🚨Runtime Error with the error and the input that caused it

##Troubleshooting

The LeetCode panel doesn't appear in JupyterLab

Check that the frontend extension is installed:

jupyter labextension list
The panel appears but questions don't load

Check that the server extension is enabled, then restart JupyterLab:

jupyter server extension list
It says my browser has no LeetCode cookie

Sign in to leetcode.com in that browser, then choose it again. Safari isn't supported because it doesn't allow other apps to read its cookies.

Where are my notebooks saved?

In the folder JupyterLab was started from, under folders like 1-50/ and 51-100/.

How do I uninstall it? 
pip uninstall jupyterlab-leetcode
